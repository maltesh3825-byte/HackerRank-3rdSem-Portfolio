# HackerRank 3rd Semester Portfolio

Solutions to five HackerRank Algorithmic Problem-Solving challenges, written in Python 3.

## Problems

| Challenge | Solution | Time | Space |
| --- | --- | ---: | ---: |
| Diagonal Difference | [solution](Diagonal%20Difference/solution.py) | O(n) | O(1) |
| Dynamic Array | [solution](Dynamic%20Array/solution.py) | O(q) | O(q) |
| Time Conversion | [solution](Time%20Conversion/solution.py) | O(1) | O(1) |
| Compare the Triplets | [solution](Compare%20the%20Triplets/solution.py) | O(n) | O(1) |
| Sparse Arrays | [solution](Sparse%20Arrays/solution.py) | O(s + q) | O(s) |

Here, `n` is the matrix dimension or score-list length, `q` is the number of queries, and `s` is the number of input strings.

## Verification

Run every solution's checks from the repository root:

```bash
python -m unittest discover -s . -p "test_solutions.py"
```

The test suite covers the official sample cases and boundary cases such as midnight, noon, empty query matches, and repeated dynamic-array lookups.
